  • 2026-10-24架体类型满堂脚手架怎么搭：36m 的条文、9m 的表格与满堂支撑架的分界满堂脚手架是作业架，满堂支撑架是承重架，两者顶部一个偏心受压、一个轴心受压。本文按 JGJ 130-2011 第 6.8 与 6.9 两节逐条对照：36m 与 30m 的高度上限、表 6.8.1 里最低只有 9m 的组合、剪刀撑 6~8m 与 5~8m 的差别、拉结竖向 4~6m 与 2~3m 的差别，以及危大判定 24m 与 5m/8m 两套门槛。
  • 2026-10-19架体类型高处作业吊篮不是小型爬架：危大身份、强条版本账与安全检查重点高处作业吊篮常被误当小型爬架。本文用官方文件讲清：吊篮属危大工程但国家层面不要求专家论证；JGJ 202-2010 五条强条属性已废止、标准仍有效；悬吊与附着失效模式不同，检查重点各异；2024 版判定标准第九条把超载、安全锁失效、安全绳未独立悬挂定为重大隐患。
  • 2026-10-15架体类型碗扣式钢管脚手架还能用吗？与轮扣式的区别及危大判定依据网传碗扣架被淘汰？住建部两批禁限目录里其实找不到「碗扣式」三个字，被限制的是轮扣式。本文讲清碗扣式钢管脚手架的定义与节点构造、与轮扣式/盘扣式的一字之差、适用场景与局限、24m 与 50m 危大判定口径，并给出 JGJ 166-2016 的构造要点及其 4 条强条被 GB 55023-2022 废止的版本状态。
  • 2026-10-14架体类型门式钢管脚手架搭设高度：55m/40m 与 45m/60m 之争，现行标准的条文对照门式钢管脚手架能搭多高？网上流传的 55m/40m 与 45m/60m 三套数字常年打架，根源是它们出自不同版本、不同用途的标准。本文逐条对照 JGJ 128-2010 表 5.1.3、JGJ 59-2011 验收表与现行 JGJ/T 128-2019，讲清现行的是哪一本、旧限值表还能不能引、门式作业架与门式支撑架有何区别，以及方案里的搭设高度到底该怎么写。
  • 2026-10-04架体类型落地式、悬挑式、附着式升降脚手架怎么选：适用场景与高度红线落地式、悬挑式、附着式升降脚手架的高度红线、危大门槛与适用场景一次说清：单排 24m、双排 50m、一次悬挑 20m、爬架四项几何参数，全部给条文出处，附选型决策清单。
  • 2026-09-12架体类型扣件式还是承插型盘扣式？脚手架选型的三个判断维度盘扣架贵在哪、值不值，扣件架现在还能不能用，政策上有没有禁限。从节点受力、搭拆效率、政策合规三个维度做对比，附选型决策表。
