方案里"脚手架类型选择"这一栏，以前基本是默认扣件式。这两年不少地方开始禁限竹木脚手架和门式钢管支撑架，盘扣架被推了上来，于是问题变成：到底该选哪个，贵出来的钱值不值。

先明确一点：**盘扣式和扣件式都合法、都能用**，选型取决于工程条件、当地政策和企业资源。下面是判断的三个维度。

## 一、节点受力：差异的根源在连接方式

两者的根本区别在立杆与水平杆怎么连。

**扣件式**靠直角扣件提供的摩擦力传力。这个摩擦力的可靠程度，取决于螺栓拧紧力矩——规范要求控制在 **40~65N·m** 之间。低于 40 会滑移，高于 65 会把扣件压裂。而这个力矩完全依赖人工，现场用扭力扳手抽检是常规动作，抽检不合格意味着整片架体的节点承载力都要打问号。

**承插型盘扣式**靠立杆上的连接盘与插销连接，插销带自锁设计，水平杆端部插入后敲紧即可。节点是**机械咬合**而非摩擦传力，承载能力高、离散性小，也不存在"拧多紧"的人为变量。

这个差异带来两个直接后果：

| 维度 | 扣件式 | 承插型盘扣式 |
|---|---|---|
| 力的传递 | 摩擦传力，依赖拧紧力矩 | 机械咬合 + 自锁 |
| 节点质量 | 离散性大，依赖人工与抽检 | 一致性好，工序标准化 |
| 被随意拆改的风险 | 高（拆个扣件就能卸掉一根杆） | 低（需整组拆卸） |
| 搭拆效率 | 慢，拧扣件占大部分工时 | 快，插入敲紧即可 |
| 立杆间距灵活性 | 高，可按需调整 | 受模数限制 |
| 材料管理 | 扣件易丢失、易锈蚀 | 构件大，管理相对容易 |

## 二、政策方向：禁限目录要提前查

这是选型时最容易被跳过、却最容易出问题的一环。

住房和城乡建设部以及多地住建主管部门陆续发布了禁止和限制使用技术目录，方向很明确：**淘汰竹（木）脚手架，限制门式钢管满堂支撑架，推广承插型盘扣式钢管支架**。GB 55023-2022 的编制说明里也体现了这个导向。

所以选型顺序应该反过来：

1. **先查项目所在地的禁限目录**，确认拟用架体在不在限制名单里；
2. 再查建设单位、总包单位的企业标准，很多大型施工企业有内部强制要求；
3. 最后才比较经济性。

在部分城市，某些类型的脚手架在特定场景下已经被明确限制使用。方案里如果还在按限制类架体编制，审查阶段就会被打回。

## 三、经济性：别只比租赁单价

盘扣架的单日租赁单价通常高于扣件架，但只看这一个数字会得出错误结论。完整算账要包括：

| 成本项 | 扣件式 | 承插型盘扣式 |
|---|---|---|
| 租赁单价 | 低 | 高 |
| 搭拆人工工时 | 高 | 低（工序减少明显） |
| 损耗与丢失 | 扣件丢失率是主要隐性成本 | 构件大，丢失少，但损坏赔付单价高 |
| 工期占用 | 长 | 短，周转次数可提高 |
| 检测与抽检 | 需抽检拧紧力矩 | 主要是构件外观与插销检查 |
| 基础处理要求 | 相对宽松 | 对立杆基础平整度、沉降更敏感 |

实践中的共识是：**面积大、搭设高度高、工期紧的项目，盘扣架的综合成本优势更容易体现；零散、异形、层高不规则的部位，扣件架反而更灵活**。很多项目的实际做法是混用——地下室外墙、机房层、局部异形部位用扣件架，标准层立面和满堂支撑用盘扣架。

## 四、选型决策表

把工程条件填进下表，倾向哪一边会比较清楚：

| 工程条件 | 倾向 |
|---|---|
| 当地政策限制或不鼓励扣件式 | 盘扣式 |
| 标准层多、立面规则、搭设高度高 | 盘扣式 |
| 满堂模板支撑，荷载大 | 盘扣式（注意 JGJ/T 231-2021 的支撑架构造规定） |
| 工期紧，周转次数要求高 | 盘扣式 |
| 异形结构、层高不统一、构件零散 | 扣件式 |
| 局部修补、洞口防护、临时性架体 | 扣件式 |
| 项目规模小，自有扣件库存充足 | 扣件式 |
| 需通过专家论证的高大支撑体系 | 优先盘扣式，构造更易满足要求 |

## 五、选盘扣架时必须注意的一条

如果选承插型盘扣式，技术依据要用 **JGJ/T 231-2021《建筑施工承插型盘扣式钢管脚手架安全技术标准》**（2021 年 10 月 1 日实施，替代原 JGJ 231-2010）。

这一版相对旧版有个重要修订：标准明确把盘扣架按用途分为**支撑架**和**作业架**两类，并且修改了荷载分项系数、增加了结构重要性系数及承载力设计值调整系数、修改了支撑架立杆计算长度公式、修订了支撑架斜杆布置的构造要求。

换句话说，**拿旧版盘扣规范或厂家的旧样本套算，结论会偏不安全**。计算书必须按 2021 版重做。

另外，无论选哪一类架体，其使用周期都要按 GB 55023-2022 的要求执行：材料与构配件在使用周期内应及时检查、分类、维护、保养，不合格品及时报废，**并形成文件记录**。这一条在老规范里没有对应的强制要求，是新增的。

## 六、一句话结论

标准层、高支模、政策收紧地区的项目，优先盘扣式，按 JGJ/T 231-2021 算；异形、零散、局部的部位，扣件式仍然好用。选型结论要写进方案的类型选择章节，并说明理由——这也是 GB 55023-2022 要求方案必须包含的内容之一。
