验收时最怕的不是发现问题，是不知道该看哪里——转一圈回来，隐患还在原地，记录上却写了"合格"。

下面这份检查表按部位组织，每一条都能在现场直接判断。依据以 **GB 55023-2022《施工脚手架通用规范》**为主，构造细节可结合相应的架体技术标准。

## 一、先明确：什么时机必须验收

脚手架不是搭完才验收一次。以下节点都应组织检查与验收：

| 序号 | 节点 |
|---|---|
| 1 | 基础完工后、脚手架搭设前 |
| 2 | 作业层上施加荷载前 |
| 3 | 每搭设完 **6~8m** 高度后 |
| 4 | 达到设计高度后 |
| 5 | 遇有**六级及以上强风或大雨后** |
| 6 | 冻结地区解冻后 |
| 7 | 停用超过**一个月**，恢复使用前 |

分段验收的意义在于：架体搭到一半时发现问题，整改成本远低于搭完之后。只做"整体验收一次"，是把风险留到最后。

GB 55023-2022 还明确了一条：脚手架搭设完成后，应办理验收手续并**出具验收合格文件**。验收必须留痕，责任要落到纸面上。

## 二、基础与地基

| 检查项 | 合格标准 |
|---|---|
| 地基平整坚实 | 满足承载力和变形要求 |
| 排水 | 已设排水措施，搭设场地不积水 |
| 冬期措施 | 已采取防冻胀措施 |
| 立杆底部 | 立杆底部设置底座或垫板，不悬空 |
| 扫地杆 | 已设置**纵向和横向扫地杆**，与相邻立杆连接稳固 |

扫地杆这一项常被漏。GB 55023-2022 明确要求底部立杆应设置纵向和横向扫地杆，两者都要有。

## 三、架体主体

| 检查项 | 合格标准 |
|---|---|
| 立杆间距、步距 | 通过设计确定，现场与方案一致 |
| 水平杆连续性 | 按步距沿纵向和横向**通长连续设置**，与相邻立杆连接牢固 |
| 节点连接 | 连接节点强度与转动刚度足够，使用期内无松动 |
| 扣件拧紧力矩 | 40~65N·m（扣件式架体抽检项） |
| 架体垂直度 | 符合规范限值，无明显倾斜 |
| 结构体系 | **未擅自改变**（GB 55023 明确使用过程中不应改变结构体系） |

## 四、连墙件（重点项）

连墙件是脚手架的生命线，也是拆除时最容易被"为了方便先拆掉"的构件。

| 检查项 | 合格标准 |
|---|---|
| 构件类型 | 能**同时承受压力和拉力**的刚性构件；**严禁**用钢丝、钢筋等柔性材料 |
| 连接对象 | 与工程主体结构可靠连接；**严禁**与施工机械设备、临时防护设施连接 |
| 水平间距 | 不超过 **3 跨** |
| 竖向间距 | 不超过 **3 步** |
| 上部悬臂 | 连墙点以上架体的悬臂高度不超过 **2 步** |
| 转角与端部 | 架体转角处、开口型作业脚手架端部**增设**连墙件，竖向间距不大于建筑物层高且不大于 4m |
| 缺失情况 | 全数检查，一处缺失即不合格 |

## 五、剪刀撑与斜撑

| 检查项 | 合格标准 |
|---|---|
| 每道宽度 | 4~6 跨，不小于 6m，不大于 9m |
| 斜杆倾角 | 与水平面成 **45°~60°** |
| 搭设高度 <24m | 两端、转角及中间每隔不超过 15m 各设一道，由底至顶连续 |
| 搭设高度 ≥24m | 全外侧立面由底至顶**连续设置** |
| 悬挑架、附着式升降架 | 全外侧立面由底至顶**连续设置**（无豁免） |
| 悬挑架水平斜撑 | 已间断设置水平剪刀撑或水平斜撑杆 |

## 六、作业面与防护

| 检查项 | 合格标准 |
|---|---|
| 脚手板铺设 | 作业层**满铺**，稳固可靠 |
| 边缘间隙 | 作业层边缘与结构外表面距离**大于 150mm** 时已采取防护措施 |
| 脚手板外伸 | 伸出横向水平杆以外部分**不大于 200mm** |
| 挂钩式钢脚手板 | 带**自锁装置**，与作业层水平杆锁紧 |
| 栏杆与挡脚板 | 作业层外边缘已设置防护栏杆和挡脚板 |
| 底层封闭 | 作业脚手架底层脚手板已采取封闭措施 |
| 水平防护 | 沿所施工建筑物**每 3 层或高度不大于 10m** 已设置一层水平防护 |
| 安全网 | 作业层外侧已用安全网封闭；密目安全网满足阻燃要求 |

水平防护和 150mm 间隙这两条是 GB 55023-2022 新增的硬指标，老的检查表里往往没有，验收时别漏。

## 七、材料与构配件

| 检查项 | 合格标准 |
|---|---|
| 质量证明文件 | 有产品质量合格证明文件 |
| 配套性 | 杆件与构配件配套使用，满足组架方式和构造要求 |
| 钢管外观 | 无严重锈蚀、弯曲、压扁、裂纹 |
| 扣件外观 | 无裂纹、变形，螺栓无滑丝 |
| 维保记录 | 使用周期内及时检查、分类、维护、保养，不合格品及时报废**并形成文件记录** |
| 性能存疑件 | 无法通过结构分析、外观和测量确定性能的，已通过**试验**确定受力性能 |

## 八、验收记录要点

一份经得起检查的验收记录，至少包含：

1. 验收部位与所属分段（对应方案的分段划分）
2. 参加验收的单位与人员，各方签字
3. 逐项检查结论，不合格项写明整改要求
4. 整改完成后的复验记录
5. 验收合格文件

别写成"经检查，符合要求"一句话结论。检查表逐项打勾 + 签字，才是留痕。

## 九、日常使用中的复检

验收合格只是起点。使用期间还应注意：

- 六级及以上强风、大雨、大雪后必须复检
- 停用超过一个月恢复使用前必须复检
- 日常巡查关注连墙件是否被拆、脚手板是否缺失、是否有超载堆料
- **作业层上的施工荷载不得超过设计允许值，严禁超载**（GB 55023-2022 明确条）
