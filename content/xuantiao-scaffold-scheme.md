悬挑式脚手架是方案编制里问题最集中的一类。原因不复杂：它悬在空中，力的传递路径比落地架多一环，构造细节一多，方案里就容易画漏、算漏。

先提醒程序上的两件事：**悬挑式脚手架无论搭设高度多少，都属于危险性较大的分部分项工程**，必须编制专项施工方案；当**分段架体搭设高度达到 20m 及以上**时，属于超过一定规模的危大工程，还要组织专家论证。判定细节见[危大工程判定清单](/news/weida-scaffold-scope/)。

## 一、方案开头要交代清楚的三件事

**分段划分。** 明确本工程悬挑架分几段、每段的起止楼层和搭设高度。这是判断是否需要论证的直接依据，也是计算书取工况的前提。常见做法是每 4~6 层一挑，单段控制在 20m 以内。

**悬挑部位的构造做法。** 悬挑梁是穿过外墙还是预埋在楼板，锚固端落在哪个构件上，这些要在方案正文里说明，不能只在图上示意。

**卸荷方式。** 是否设置钢丝绳或钢拉杆斜拉卸荷，设置在哪一层，间距多少。

## 二、构造上的关键数字

以下是悬挑架方案中必须明确的构造要求，也是评审时专家最常追问的地方：

| 构造项 | 要求 |
|---|---|
| 悬挑梁选型 | 宜采用**双轴对称截面**型钢（工字钢），钢梁截面高度**不应小于 160mm** |
| 锚固长度 | 悬挑梁**固定段长度不应小于悬挑段长度的 1.25 倍** |
| 锚固件 | 固定端应采用 **2 个（对）及以上** U 型钢筋拉环或锚固螺栓与梁板固定 |
| 锚固件位置 | 预埋至混凝土梁、板**底层钢筋**位置，并与底层钢筋焊接或绑扎牢固 |
| 卸荷装置 | 悬挑梁前端宜设置钢丝绳或钢拉杆与**上一层**建筑结构斜拉结 |
| 立杆底部 | 悬挑脚手架立杆底部应与悬挑支承结构可靠连接 |
| 扫地杆 | 应在立杆底部设置**纵向扫地杆** |
| 水平斜撑 | 应**间断设置**水平剪刀撑或水平斜撑杆 |
| 剪刀撑 | 悬挑脚手架应在**全外侧立面**上由底至顶**连续设置**竖向剪刀撑 |

几个容易踩坑的点：

**锚固长度 1.25 倍是硬要求。** 现场为了减少楼板预留洞，常把固定端做短，这是典型的隐患。悬挑段越长，固定段要跟着变长，方案里应给出每个部位的具体尺寸而不是笼统说"满足规范"。

**卸荷钢丝绳不参与计算。** 这一点经常被搞反。钢丝绳或钢拉杆属于安全储备，计算书里**不应**把它当作悬挑梁的支点来减小计算跨度。如果方案里出现了"考虑钢丝绳卸荷，悬挑梁按两点支承计算"这种写法，逻辑上就是错的。

**剪刀撑必须全立面连续。** GB 55023-2022 对悬挑脚手架和附着式升降脚手架的要求是全外侧立面由底至顶连续设置，没有 24m 的门槛豁免。

## 三、计算书要算的四项

悬挑架计算书比落地架多一层——既有架体本身的验算，又有悬挑支承结构的验算。完整的验算链条是：

| 序号 | 验算内容 | 要点 |
|---|---|---|
| 1 | 立杆稳定性 | 取最不利立杆，按最不利工况组合荷载 |
| 2 | 连墙件承载力 | 刚性构件，承受风荷载产生的拉压 |
| 3 | **悬挑梁强度与挠度** | 按悬挑构件计算，挠度限值 l/400，l 取悬伸长度的 **2 倍** |
| 4 | **锚固件与锚固段验算** | U 型拉环/螺栓的抗拉、抗剪，锚固长度 |
| 5 | 楼板局部承压 | 悬挑梁支座处楼板的抗冲切、局部受压 |

第 3 项和第 4 项是悬挑架特有的，也是最容易算得不细的部分。

荷载组合要按 GB 55023-2022 的要求来：永久荷载与可变荷载分别组合，取最不利组合；存在 2 个及以上作业层同时作业时，同一跨距内各操作层施工荷载标准值总和**不应小于 5.0 kN/m²**；有动力荷载时乘动力系数 **1.35**。

## 四、方案里最常被退回的五处

1. **只有立面示意，没有节点详图。** 悬挑梁与结构的连接节点、立杆与悬挑梁的连接节点，都要有能指导施工的详图。
2. **分段高度没写清。** 直接导致无法判断论证层级。
3. **计算书用旧模板。** 荷载取值、挠度限值还是老规范的口径。
4. **构造措施与计算模型对不上。** 例如计算按铰接受力、构造上做成刚接，或者反过来。
5. **缺拆除方案。** GB 55023-2022 明确的方案内容里包含搭设、拆除施工计划和技术要求，悬挑架的拆除（尤其是卸荷钢丝绳的拆除顺序）比搭设更危险，不能省。

## 五、编制顺序建议

按这个顺序走，效率最高也不容易漏：

1. 定分段 → 定各段高度 → 判断是否需论证
2. 选悬挑梁型号（先按不小于 160mm 的截面高度选，再验算）
3. 定锚固方案（拉环还是螺栓、位置、固定段长度）
4. 定卸荷方案（钢丝绳规格、拉结点层位）
5. 建模算立杆稳定性 + 悬挑梁 + 锚固件
6. 画构造图（平面、立面、节点详图）
7. 写搭设与拆除技术要求、质量控制、安全措施、应急预案
